# Evolution Planning

Use this skill when turning an approved mutation packet into a bounded implementation plan.

- Treat the candidate workspace as the only writable source tree.
- Trace the requested behavior to the smallest load-bearing architecture boundary before editing.
- Preserve Sinomo networking, storage, authority, trust-ring, and module boundaries.
- State the acceptance evidence before changing code, including focused tests and rollout gates.
- Prefer reversible, reviewable changes and record any assumption that changes the mutation scope.
